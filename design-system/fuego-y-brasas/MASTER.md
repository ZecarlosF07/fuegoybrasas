# Fuego y Brasas — Entrada del sistema visual

**Versión:** 1.0 · **Fecha:** 3 de octubre de 2026.  
**Estado:** diseño especificado; base visual de H1 implementada y en revisión. Interfaces de H2–H8 pendientes.

Este archivo permite recuperar el sistema desde el flujo de `ui-ux-pro-max`. **Antes de diseñar, construir o revisar una página, leer completos:**

1. [Sistema visual canónico](../../.agents/brand/sistema-visual.md): única definición de tokens, medidas, componentes y patrones.
2. [Reglas UX/UI](../../.agents/rules/ux-ui.md): skill, interacción, accesibilidad y evidencia.
3. [Hito correspondiente](../../docs/implementacion/hitos-del-proyecto.md) y sus contratos/rutas.

Los valores no se duplican aquí. Este MASTER es una entrada que remite a la fuente de verdad; no una plantilla automática persistida por la skill. No existen overrides de páginas en esta entrega. Patrones particulares están en el sistema canónico y la [cobertura de vistas](../../docs/diseno-tecnico/14-identidad-visual-y-sistema-ui.md).

No reemplazarlo con `--persist --force` ni crear otra paleta. Una excepción se documenta en la fuente canónica con motivo/alcance, sin reescribir acuerdos funcionales. Recomendaciones genéricas requieren verificar su encaje y compatibilidad con Next.js instalado.

Fundamento: [Investigación y referentes](../../docs/diseno-tecnico/15-investigacion-ux-y-referentes.md).
